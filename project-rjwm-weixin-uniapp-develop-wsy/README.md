# 数码零售商城小程序

## 项目说明

这是一个基于 `uni-app` 开发的微信小程序项目，当前产品定位为**数码零售商城**。

当前版本的核心结构：

- **首页**：门户入口页，承载商城入口与手机型号推荐入口
- **商城页**：浏览分类商品、查看商品详情、维护购物清单
- **手机型号推荐页**：按手机型号查看推荐商品
- **个人中心**：查看历史订单、进入推荐页等个人相关入口

> 说明：当前版本已移除地址簿相关能力，支付功能暂未开放；门店信息/导航能力后续再补。

## 开发环境准备

### 1. 注册/准备小程序 AppID

前往[微信公众平台](https://mp.weixin.qq.com/)注册或登录小程序账号，在开发管理中获取 AppID。

**注意：**
- AppID 在开发和真机调试时会用到
- 开发阶段也可以临时使用测试号

### 2. 安装开发工具

- 安装 **HBuilderX**：<https://www.dcloud.io/hbuilderx.html>
- 安装 **微信开发者工具**：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

---

## 项目运行

### 使用 HBuilderX 新建/导入项目

#### 新建项目

- 打开 HBuilderX
- 菜单栏选择：**文件 -> 项目 -> 新建**
- 选择 `uni-app`
- 填写项目名称和目录

#### 导入已有项目

- 打开 HBuilderX
- 菜单栏选择：**文件 -> 导入 -> 从本地目录导入**

### 运行到微信开发者工具

在 HBuilderX 中：

- 点击菜单栏 **运行**
- 选择 **运行到小程序模拟器 -> 微信开发者工具**

**注意：**
- 第一次使用时，需要先在 HBuilderX 中配置微信开发者工具路径
- 微信开发者工具需开启服务端口

## 目录说明

- `pages.json`：页面路径、窗口样式、tabBar 等全局页面配置
- `manifest.json`：应用名称、图标、权限等配置
- `App.vue`：应用入口文件
- `main.js`：项目入口文件，初始化 Vue 实例
- `pages/`：页面目录
- `components/`：组件目录
- `static/`：静态资源目录
- `unpackage/`：打包产物目录

---

## 开发规范补充

为兼容多端运行并保持开发效率，建议遵循以下规范：

- 页面文件遵循 Vue SFC 规范
- 组件与 API 使用方式优先遵循 `uni-app` 规范
- 数据绑定与事件处理遵循 `Vue.js` 规范
- 页面布局优先使用 flex
